# Monotonicity of squares

**Abstract.** We show that squaring is monotone on the non-negative integers, and derive two consequences on shifted squares.

## 1. Definitions

**Definition 1.** For an integer n, sq(n) = n · n.

## 2. Results

**Lemma 2.** For all integers x and y with 0 ≤ x ≤ y, sq(x) ≤ sq(y).

*Proof.* From 0 ≤ x ≤ y, x · x ≤ x · y ≤ y · y. ∎

**Proposition 3.** For all integers x and y with x ≤ y, sq(x) ≤ sq(y).

*Proof.* By Lemma 2. ∎

**Theorem 4.** For every integer m and every integer d ≥ 0, sq(m) ≤ sq(m + d).

*Proof.* Since d ≥ 0, m ≤ m + d, and Proposition 3 applies. ∎

**Proposition 5.** For every integer n ≥ 0, sq(n) ≤ sq(n + 1).

*Proof.* We have 0 ≤ n ≤ n + 1, and Lemma 2 applies. ∎
